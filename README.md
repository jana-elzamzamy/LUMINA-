Lumina 🌟

An intelligent platform designed to help people with visual and hearing disabilities interact more easily with the digital and physical world using Artificial Intelligence.

📌 About the Project

Lumina provides smart accessibility tools that help users:

Understand images
Convert text into speech
Communicate using sign language

The platform aims to make technology more inclusive and easier to use for everyone.

✨ Main Features
🖼️ Image Description for the Blind

Users can upload an image or capture one using the camera.
The system will:

Analyze the image
Generate a description
Convert the description into speech
✋ Sign Language Translation

Users perform hand gestures in front of the camera.
The system will:

Recognize sign language gestures
Convert them into text
🔊 Text-to-Speech

Users can upload text or files.
The system will:

Convert text into speech

Useful for:

Blind users
Elderly people
Users with visual impairments
People with reading difficulties
